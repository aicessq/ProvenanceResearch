# 本地知识库正式自动化测评计划（2026-10-26）

用户要求生成合理测评并真实执行，用于可核查的简历项目描述。本计划冻结后才运行正式测量，不以结果好看为理由改题、换模型、丢弃失败或调整阈值。

## 测试边界

- 60 题：36 单来源、12 多来源、12 证据不足；48 道可答题中 32 道英文、16 道中文，拒答题为中文。多来源不全部等同于需要推理链的多跳。
- 16 份仓库已有、具有文本层的固定公开原文（法律、RFC、NIST）；5 份扫描件和仓库外论文不进入本次文本测评。保留来源地址、版本、原文件 SHA256；不修改旧 56 题、18 题冻结件或 verified 字段。
- 新题为源文片段锚定的候选标注，每条可答要点必须在指定来源页逐字核对通过程序校验。人工语义核验数仍为 0；不把自建候选集包装成公共权威榜单或人工金标准。
- 英文 Embedding BAAI/bge-base-en-v1.5，本机 768 维、归一化；reranker 关闭。固定检索过滤器为整个测试语料的 law/standard 两类，不给检索器目标文档、页码或答案。
- 独立 PostgreSQL 数据库、Qdrant collection、Redis DB 和存储目录；采用生产上传、Worker、检索 API 与证据工具。既有用户文档不增删，不使用 fake、确定性词面模拟 Embedding 或直写伪向量。

## 检索测量

60 题随机固定顺序，各运行 3 次真实 HTTP 检索；一次返回生产 debug 中的 PostgreSQL FTS、BGE 向量及 RRF 混合排序。FTS 使用现有 simple 配置，不称 BM25。统一查询改写和固定类型范围，报告三路区别。

只在 48 道可答题计算 Evidence Recall@1/5/10：目标来源 UUID 相同且检索文本包含完整标注片段，才视为要点命中；分母为该题全部标注要点。MRR 为首个命中要点的倒数排名。多来源另外报告全部要点覆盖率。引用片段标注并不穷尽所有正确转述，指标属于严格片段命中口径。

报告英文/中文/单来源/多来源分组、查询级 bootstrap 95% 区间、三次重复的一致性，以及请求 p50/p95。重复测量不当作三倍独立题目。单独记录模型预热，正式延迟不含首次模型加载；同一次混合请求返回三路结果，HTTP 耗时是整个混合路径耗时，不冒称单路向量耗时。

## 真实 Agent 对照

60 题各运行原始固定提交 loop 和当前 loop 一次，共 120 次；复用当前真实 provider、工具和证据环境。两组采用同一语料、Agnes 模型、temperature=0、每次最大输出 1024 token、最多 3 轮/5 次工具/8000 token 预算及 120 秒任务截止时间；实际调用的输入 token 可能使软 token 预算越界，必须如实报告，不宣称绝对硬费用上限。仅开放本地 kb_search 和 evidence_read，不允许联网或凭模型记忆补足缺失事实。

保存每题回答、claims、引用、证据全文、拒答原因、工具错误、用量和停止原因。报告可答题作答率、误拒率、目标事实引用覆盖、引用身份完整率、证据不足题拒答行为、运行故障、实际 token、p50/p95。错误和超时保留在分母中；invalid_planner_output、预算/截止停止单独统计，不把这类运行业务失败称为正确拒答。内部同模型语义闸门不充当独立质量裁判；不以逐字覆盖或引用身份指标命名“答案准确率”。

模型单次运行存在随机性，本次不是多次生成方差或大规模线上负载实验。没有美元价格表时报告已知 token、未知费用，不虚构金额或并发吞吐。

## 验收与交付

脚本指标回归通过、源文标注校验通过、真实入库全部 completed、测试库文档/索引身份可审计后冻结配置并提交。正式运行保留完整逐题 JSONL 和机器配置，包含数据/配置/代码指纹；逐题输出单独供人工复核。

最终报告给出实际结果、失败分析和可用于简历的保守表述，只引用本次真实测量；效果差也照实呈现，不临时优化后覆盖同一轮结果。本次自动化测量不将旧 P4 的人工金标准或多模态验收标为完成。

RFC 原件为 TXT，生产解析器将其作为单页文档；原始页标注只用于源文锚定，不据此声称 RFC 页码定位准确率。本轮不测 OCR、视觉、扫描件、线上吞吐或人工语义准确率。
